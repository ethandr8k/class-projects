# Class Projects

This repository contains selected projects from my undergraduate coursework in mathematics, physics, and computer science at Simpson College. These projects explore mathematical reasoning, computational modeling, and quantitative approaches to scientific problems.

## Projects

### 1. Extensibility of Poly-Catenane Structures

**Course:** Thermal Physics

Investigates the physical properties and configurational behavior of polycatenane structures using the Metropolis Monte Carlo method. The project applies statistical mechanics and computational simulation to study complex interlinked ring polymers.

**Key concepts:** Monte Carlo simulation, statistical mechanics, computational modeling, polymer physics.

[View Project](Extensibility_of_Poly_Catenane_Structures.pdf)

### 2. Mechanical Analysis of Two-Axis Clinostats

Develops a mathematical framework for analyzing two-axis clinostat motion and its ability to approximate time-averaged microgravity conditions. The project investigates rotational kinematics and the time-dependent orientation of the gravity vector in a rotating reference frame.

**Key concepts:** Mathematical modeling, rotational kinematics, vector analysis, differential equations, space biology.

[View Project](Mechanical_Analysis_of_Two_Axis_Clinostats.pdf)

### 3. Introduction to Advanced Mathematics — Final Portfolio

Final Portfolio of proofs and class reflection from my Intro to Advanced Math course. Collection of proofs are provided at the end of the paper. 

**Key concepts:** Mathematical proofs, analytical reasoning, abstract mathematics.

[View Project](Intro_to_Advanced_Math_Final_Portfolio.pdf)

### 4. Understanding Analysis — Write-Up

Final Presentation for Real Analysis explaining Cantor's Diagonalization Theorem and the countability of the Real Numbers

**Key concepts:** Real analysis, proof writing. 

[View Project](Understanding_Analysis_1.6_Write_Up_Final.pdf)
